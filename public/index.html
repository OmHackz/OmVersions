Version API for GitHub releases

OmVersions is a lightweight, centralized version API that automatically fetches releases from registered GitHub repositories. Register a project once in projects.json and the API exposes its releases, latest version, assets, and update checks — no manual version entry required.

Base URL https://version.omhackz.top/api/v1
