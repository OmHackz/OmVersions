OmVersions

A centralized version API that automatically fetches releases from registered GitHub repositories. Register a project once in projects.json and the API exposes releases, latest versions, assets, and update checks — no manual version entry required.

Base URL https://version.omhackz.top/api/v1

Add a project by editing projects.json and pushing to main. No code changes required.

Endpoint examples

GET /api/v1/helio/latest

Latest stable release for Helio.

GET /api/v1/helio/latest?channel=beta

Latest beta release.

GET /api/v1/helio/check?current=1.0.0

Check whether an update is available.

GET /api/v1/helio/releases

Full release history.
